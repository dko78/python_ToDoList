# Web scraping – početni projekt

Mali Python primjer koji preuzima javnu testnu stranicu i ispisuje njezin naslov te naslove članaka. Koristi `requests` za preuzimanje HTML-a i `BeautifulSoup` za njegovo čitanje.

## Pokretanje

1. Otvori terminal u mapi `WebScraping`.
2. Instaliraj biblioteke:

   ```powershell
   python -m pip install -r requirements.txt
   ```

3. Pokreni program:

   ```powershell
   python main.py
   ```

Primjer koristi `https://quotes.toscrape.com/`, stranicu namijenjenu vježbanju web scrapinga.
